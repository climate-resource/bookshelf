A base URL carrying a query string, a fragment, a `user@` part or a trailing `/v1` now raises `ConfigurationError` (CLI exit 2), and the message names whichever of `--api-url`, `$BOOKSHELF_URL`, `$BOOKSHELF_API_URL` or `base_url` supplied it.
`bookshelf auth list` `expired` now says whether the access token has expired, even when a refresh token can renew it, and the new `needs_login` field carries the old meaning.
