Slims the `publish` extra to the two libraries notebook capture actually imports.

- Drops `papermill`, which nothing has imported since the recorder replaced the papermill path
  with `execute_python_build`. It brought the whole `aiohttp` stack with it.
- Drops the explicit `jupyter-client` and `ipykernel` pins, which existed for papermill's kernel.
  `nbconvert` still pulls what it needs.
- Declares `nbformat`, which the renderer imports directly and which was only ever present by chance.

`bookshelf record` no longer refuses to run when `papermill` is absent.
It now checks for `nbformat` and `nbconvert`, the libraries it goes on to use.
