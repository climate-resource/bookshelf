Removed the asynchronous surface, so every method exists once and is synchronous.
Upgrading from 1.0.0rc2:

- `AsyncBookshelf`, `AsyncVolume`, `AsyncBook`, `AsyncBookEntry`, `AsyncResource`, `AsyncActivity`
  and `AsyncDraftBook` were removed. Use `Bookshelf` and its handles.
- `bookshelf.publisher.replay_bundle` is now synchronous and takes a `Bookshelf`.
  `replay_bundle_sync` was removed, because `replay_bundle` replaces it.
- The `async_transport=` test seam went with `AsyncBookshelf`. Pass a synchronous `transport=` to `Bookshelf`.

From async code, run each call in a worker thread:

```python
book = await asyncio.to_thread(bs.book, "rcmip-emissions", "v5.1.0")
frame = await asyncio.to_thread(book["magicc"].as_df)
```

One `Bookshelf` can be shared between those threads.
