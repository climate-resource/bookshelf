Moves `--api-url` onto the `bookshelf` command itself, ahead of the subcommand.

Run `bookshelf --api-url URL publish bundle` where it used to be
`bookshelf publish bundle --api-url URL`.
The old position is now a usage error naming the option, so a stale call fails rather than
quietly reaching the default deployment.
`$BOOKSHELF_URL` is unaffected.
