Adds catalogue discovery to the `Bookshelf` and `AsyncBookshelf` facades.

- `search_volumes()` finds volumes by free text over name, title and summary,
  plus the discovery filters the CLI already accepted:
  `topic`, `keyword`, `region`, `publisher`, `license`, `coverage_year`,
  `resource_type` and `deprecated`. Filters combine with AND,
  and calling it with no arguments lists the catalogue.
- `list_books()` returns every book in one volume, oldest first.
  It walks the pages itself, and orders versions component by component
  so `v2.10` follows `v2.9` rather than preceding it.

Both operations already existed on the transport and behind `bookshelf search`.
Only the Python facade was missing them, so a caller had to reach into the private
client to answer "what is on the shelf", which the V1 library could do through
`list_versions()`.

Comes with a how-to guide covering search, filtering, paging and listing a volume's books.
