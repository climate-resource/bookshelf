# Legacy (0.4)

`bookshelf.legacy` keeps the 0.4 consumer API working on top of `Bookshelf`.
Every call warns with a `DeprecationWarning`.
The module is removed in bookshelf 1.1, once the feedstocks have migrated,
so it sits outside the [semver promise](index.md#what-semver-covers).
See [Migrating from 0.4](../migrating.md) for the replacements.

::: bookshelf.legacy
