Changed `bookshelf validate --json` to report `processing` as `{"code_ref": ..., "config_hash": ...}` objects
rather than two-item lists, so the human output no longer prints Python list reprs.

Changed a recorded `activity()` to refuse an explicit `activity_id` together with a `config_hash`
that is not the digest of its parameters, because validation could then never tell an edited envelope apart.
Pass one of them and let the other be derived.
