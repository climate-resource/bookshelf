# Auth

`bookshelf.auth` resolves a Bookshelf credential for use against other Climate Resource services.
See [Use a Bookshelf login against another service](../authentication.md#use-a-bookshelf-login-against-another-service)
for how to use it.

The four names below are the promised surface.
The other names in `bookshelf.auth.__all__`, such as `ActionsOidcToken` and `TokenProvider`,
are importable but may change in any release.
