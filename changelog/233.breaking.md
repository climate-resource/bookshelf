Changed the converters to read the whole resource instead of a server trimmed preview.
Previously `book[name].as_df()` silently stopped at 10000 rows for timeseries.

- `as_df()`, `as_long_df()`, `as_scmrun()`, `as_polars()` and `as_arrow()` accept only `year_min`, `year_max` and `column=value` filters, applied locally after the download.
- A filter on a column the resource does not have raises `KeyError`.
- Added `query()`, which keeps the server side trimming, including `top_n`, `drop_constant`, `limit`, `select`, `order` and `offset`.
  Calls passing those arguments to a converter need to move to `query()`.
