Serialises a pandas frame to the same parquet bytes as the equivalent polars frame for every column type,
so a record hashes the same whichever library built it.

- Casts string, binary, list and struct columns to large offsets and categorical indices to `uint32`,
  the widths polars already writes.
- Drops library metadata from every column, such as the category labels newer polars attaches.
- Changes the hash of a resource built from pandas on pandas 2.x,
  or from a pandas frame holding binary, list, struct or categorical columns.
  Re-recording such a book publishes new bytes rather than converging.
