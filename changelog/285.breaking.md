Errors now follow one contract.

- Looking up a missing entry with `book["name"]` now raises `EntryNotFoundError`, which is still a `KeyError`.
- Filtering on an unknown column now raises `SelectionError`, which is still a `KeyError`.
- `NotFoundError` is now also a `LookupError`.
- `Bundle.read` now raises `InvalidBundleError` for invalid YAML, a bad `schema_version` or a manifest the schema rejects.
- `load_record_recipe` now raises `InvalidRecipeError`, and parsing a `bookshelf://` reference raises `InvalidReferenceError`.
- `InvalidBundleError`, `InvalidRecipeError` and `InvalidReferenceError` are all `ValueError` subclasses.
- The HTTP 400/422 error was renamed from `ValidationError` to `RequestValidationError`, so it no longer shares a name with pydantic's.
