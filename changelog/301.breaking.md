The CLI's `--json` output uses one spelling per concept, so these keys are renamed:

- `show` on a book: `resources` is now `entries`, and each entry's `bytes` is now `size_bytes`.
- `show` on an entry: `bytes` is now `size_bytes`, and the new `address` names the entry.
- `record`, `validate`: `resources` is now `resource_count` and `book_entries` is now `entry_count`.
- `publish`: `resources` is now `resource_count`.
- `upload`: `hash` is now `content_hash`.
- `cache info`: `total_bytes` is now `total_size_bytes` and `max_bytes` is now `max_size_bytes`.
- `cache prune`: `bytes_freed` is now `freed_size_bytes`, and `total_bytes` and `max_bytes` are renamed as for `cache info`.
- `cache clear`: `bytes_freed` is now `freed_size_bytes`.

The CLI is outside the semver promise, see the new command line page.
