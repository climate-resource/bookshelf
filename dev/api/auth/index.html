    Auth#

    bookshelf.auth resolves a Bookshelf credential for use against other Climate Resource services. See Use a Bookshelf login against another service for how to use it.

    The four names below are the promised surface. The other names in bookshelf.auth.__all__, such as ActionsOidcToken and TokenProvider, are importable but may change in any release.

    bookshelf.auth.default_auth #

    default_auth(api_url: str | None = None, *, strict: bool = False) -> httpx.Auth | None

    Return the credential a Bookshelf client would use, or None when there is none.

    Tokens refresh ahead of expiry and once after a 401. A stored login whose refresh fails degrades to unauthenticated requests with a warning, unless strict asks for the AuthenticationError instead. api_url picks which Bookshelf deployment's stored login to use.

    bookshelf.auth.access_token #

    access_token(api_url: str | None = None, *, timeout: float = 30.0) -> str | None

    Return a current bearer token, refreshing it first when one is due.

    Returns None when no credential is configured. timeout bounds the token exchange, in seconds. Raises AuthenticationError when the credential cannot be refreshed. A token rotated by the refresh is written back to the credential store.

    bookshelf.auth.StaticToken #

    StaticToken(token: str)

    A fixed bearer token, sent exactly as given and never refreshed.

    bookshelf.auth.ClientCredentials #

    ClientCredentials(client_id: str, client_secret: str, *, token_url: str)

    An OAuth2 client_credentials machine credential.

    The pair is exchanged at token_url for an access token, and exchanged again once it expires.
