Adds executed how-to guides covering both sides of the SDK.

- Reading a published book addresses a book, pins an edition, and trims a query on the server.
- Converting and plotting covers the pandas, Polars, PyArrow and `ScmRun` converters,
  along with the verified content cache.
- Reading asynchronously covers the awaited facade, concurrent fetches, and client lifetime.
- Publishing a book frames a book and registers a derived resource with its lineage.
- Cataloguing external data covers external pointers, batch registration and deduplication.

Each guide is executed when the docs are built, so its output is real.
Reads run live against the deployment, while the producer guides record into a bundle
rather than publishing, so the whole build runs unauthenticated and writes nothing.
Both producer guides show the authenticated replay step without running it.
The docs environment gained the `dataframes` and `scmrun` extras plus `seaborn` to support this.

Also corrects the entry name in the existing examples, which was `magicc-rcmip` and is `magicc`,
and the claim that book timeseries queries accept the `col.op` filter grammar.
That path takes bare `column=value` filters and ignores anything else.
