Adds `bs.use("raw")`, which resolves a resource the recipe declares for the selected version,
so a feedstock declares an upstream file once, in YAML, and reads it with two lines of Python.

- A `uri` resource is fetched through the content cache and verified against its declared `sha256`.
  A repeat build with the same digest makes no network call, and a mismatch fails without retrying.
- A `path` resource is read from beside the recipe, wherever the build is run from,
  and its digest is computed as it is read.
- Both are registered as external pointers, carrying the version's `doi` where it declares one.
