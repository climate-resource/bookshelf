The local cache now remembers each resource's hash and every pinned book edition,
so a warm `as_path()` or `fetch()` on `book(volume, version, edition=n)` makes no request at all.
A remembered edition is checked with one request once a day, in case it was retracted.
Tune the window with `Bookshelf(book_ttl=seconds)` or `BOOKSHELF_CACHE_BOOK_TTL`.
The latest edition lookup is unchanged and always asks the platform.
