Adds executed how-to guides covering both sides of the SDK.

- Reading: addressing a book, pinning an edition, exploring an entry, and trimming a query on the server.
- Converting: the pandas, Polars, PyArrow and `ScmRun` converters, the verified content cache, and plotting.
- Reading asynchronously: the awaited facade, concurrent fetches, and client lifetime.
- Publishing: framing a book, registering a derived resource with its lineage, and reading the recorded manifest.
- Cataloguing: external pointers, batch registration, partial failure, and deduplication.

Each guide is executed when the docs are built, so its output is real.
Reads run live against the deployment.
The producer guides record into a bundle rather than publishing,
so the whole build runs unauthenticated and writes nothing.
Both show the authenticated replay step without running it.
The docs environment gained the `dataframes` and `scmrun` extras plus `seaborn` to support this.

Also corrects the entry name in the existing examples, which was `magicc-rcmip` and is `magicc`,
and the claim that book timeseries queries accept the `col.op` filter grammar.
That path takes bare `column=value` filters and ignores anything else.
