Ships pandas and PyArrow as core dependencies,
so `pip install bookshelf` is enough for `as_df()`, `as_arrow()` and writing parquet.

- Raises the minimums to pandas 2.3, PyArrow 18 and Polars 1.8, following [SPEC 0](https://scientific-python.org/specs/spec-0000/).
- Keeps `dataframes` as an empty extra, so older install lines still resolve.
- Stops installing Polars with `bookshelf[dataframes]`.
  Install it yourself to use `as_polars()`, which raises `DataFrameSupportError` naming the missing package.
