Collapses the four hand-rolled copies of the token exchange onto the credential providers.

- `bookshelf auth token` now asks the provider for a token instead of deciding staleness itself,
  so printing a token and sending a request share one grant, one refresh window,
  one single-flight lock and one write back to the credential store.
  A stored login with a refresh token but no recorded expiry is now refreshed before it is printed,
  where it used to be printed as it stood.
- The WorkOS client ID and base URL have one definition and one resolver
  rather than a copy in the OAuth flows and another in ambient resolution.
- A rotation is now expressed as the stored record carrying a new token,
  so the subject, the organisation and the claim it was bound to cannot be dropped on the way through.
- The identity kind is an enum. The stored file format is unchanged.
