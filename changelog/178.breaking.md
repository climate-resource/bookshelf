Replaced the flat recipe with `volume:`, `build:` and `releases:` sections,
and made `bookshelf record --version` required.

- A recipe declares the volume once, the build once, and each release explicitly.
  The releases can live in `bookshelf.yaml` or in one file per release under `releases/`,
  and both layouts load to the same recipe.
- Unknown keys are rejected at every level, rather than silently ignored.
- `visibility` moved under `build:`, and `collection`, `license`, `authors` and `notebook`
  moved under `volume:` and `build:`.
  The flat form no longer loads, and a recipe using it is rejected with a message naming the new shape.
- `--version` selects the release to record, and it is the only place a version is stated.
  A build file calls `bookshelf.setup()` without a version, and `-p` is unchanged.
