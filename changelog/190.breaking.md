Refreshed the vendored API contract onto the platform's bundle replay endpoint and its content-only seal.

- `draft_book(citation_doi=...)` was removed, along with `citation_doi` on the bundle's book framing.
  A book states its DOI through `discovery`, so pass `discovery={"doi": ...}` instead.
- `RegistrationOutcome.aliased_to` was removed.
  `tracking_id` is canonical on every status, so an aliased outcome already reports the resource
  the proposed id collapsed onto.
