Changed the converters to read the whole resource instead of a server trimmed preview.
Previously `book[name].as_df()` silently stopped at 10000 rows for timeseries.

- Restricted `as_df()`, `as_long_df()`, `as_scmrun()`, `as_polars()` and `as_arrow()`
  to `year_min`, `year_max` and `column=value` filters, applied locally after the download.
- Made a filter on a column the resource does not have raise `KeyError`.
  The `col.op` filter grammar, such as `region.in`, moved to `query()` with the other server side arguments.
- Added `query()`, which kept the server side trimming,
  including `top_n`, `drop_constant`, `limit`, `select`, `order` and `offset`.
  Calls that passed those arguments to a converter moved to `query()`.
