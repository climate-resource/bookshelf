Keeps the default deployment and the active identity unchanged when a stored login's token is refreshed.
Refreshing a staging client used to make staging the default.

Skips writing a refreshed token when the stored login has changed since it was loaded,
so a refresh no longer overwrites a newer login or brings back one that was logged out.

`bookshelf auth whoami --offline` reports client credentials as kind `machine` instead of `user`.
