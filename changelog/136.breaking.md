Changes two behaviours a caller can observe:

- Serialising a `DataFrame` without the `dataframes` extra raises `DataFrameSupportError`
  rather than `ImportError`.
  Code catching `ImportError` around a produce call needs updating.
- The SDK and the CLI now share one SemVer version ordering, so they agree on which book is the newest.
  This changes the order `list_books()` returns for volumes that publish prerelease versions.

Follows the platform's one discovery contract, which removes every duplicate mechanism for a descriptive fact:

- Removes `abstract` from the recipe's `defaults:` section. A dataset summary is `description`, which is the name the platform carries and the one producers already use.
- Sends `description` and `authors` inside the book's `discovery` object rather than beside it, matching where the platform now carries them.
- States the licence on every book the recipe resolves. The platform no longer defaults a draft's licence from its volume, so the producer resolves it, which is what the recipe's `defaults:` section was always for.
