Reworks the resource read interface,
so `Resource` and `BookEntry` take one selection and answer it the same way:

- Removes `query()`.
  Use a converter for complete data, or `preview()` for a bounded sample.
  `select` and `offset` remain on the low-level client's `query_resource_data()`.
  Removes `BookshelfClient.query_resource_dataframe()` too, so convert its payload with pandas directly.
- Takes filters as `filters={"region": ["World", "OECD"]}` rather than `region="World"` keywords.
  Values listed for one column are alternatives, and separate columns must all hold.
- Raises `SelectionError` for an unknown filter column, rather than `KeyError`.
  A value the column cannot be read as, such as `"abc"` on a numeric column,
  raises it too rather than matching nothing.
  `None` or `""` must be a filter's only value, because the platform cannot combine them with others.
  A converter passed a `query()` argument such as `top_n` now raises `TypeError` from Python itself.
- Returns a `DataPreview` from `BookEntry.preview()`, with the rows in `data` and a `completeness` flag.
  It no longer takes `offset`.
- Renames `BookEntry.schema()` to `series_metadata()`, because it lists series rather than columns.
- Takes `filters=` in `BookEntry.facets()` rather than keyword filters.
- Replaces the `Resource.metadata` and `Resource.type` properties with `describe()` and `resource_type()`,
  which `AsyncResource` now offers too.
- Labels the year columns of a wide timeseries frame as strings whatever the stored shape.
  A file stored in long form used to give integer labels.
- Stops printing a resource or entry from contacting the platform,
  so a typeless entry prints as `unknown` until its type is read.
