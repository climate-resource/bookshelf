Changed the converters (`as_df()`, `as_long_df()`, `as_polars()`, `as_arrow()` and `as_scmrun()`)
to read the verified file in the content cache instead of asking the server to convert the resource on every call.
A second conversion, or one after `as_path()`, now costs no download.
A CSV resource is parsed by pandas rather than by the platform, so column types inferred from an unusual CSV can differ.

Made `ContentCache.metadata` private and removed `MetadataCache` from `bookshelf.cache.__all__`.
