The Python API no longer returns the generated API models, so they can track the platform freely.
Upgrading from 1.0.0rc1:

- `Book.metadata` is now the book's free-form metadata dict.
  Read `book.volume`, `book.version`, `book.edition`, `book.status`, `book.visibility` and `book.published_at`
  in place of `book.metadata.<field>`.
- `Volume.metadata` is now the volume's free-form metadata dict.
  Read `volume.title`, `volume.description`, `volume.license` and `volume.discovery` in place of `volume.metadata.discovery`.
- `BookEntry.entry` was removed. Use `entry.name_in_book`, `entry.visibility` and `entry.resource_type()`.
- `search_volumes()` returns `VolumeSearchResults` holding `VolumeSummary` items.
  A summary carries `license`, `title` and `description` as plain strings,
  so `volume.discovery.license.root` becomes `volume.license`.
- `facets()` returns `Facets` and `series_metadata()` returns `SeriesMetadata`, with the same field names as before.
- `ensure_authenticated()` returns an `Identity`.
- `resource_type()` returns `bookshelf.ResourceType`, whose members are upper case, such as `ResourceType.TIMESERIES`.
  Comparing it with a string still works.
- `ResourceInfo.type` and `ResourceInfo.hash` were renamed `resource_type` and `content_hash`, matching the handle methods.
  `ResourceInfo.record` and `ResourceInfo.from_record()` were removed.
- `APIError.problem` is a `bookshelf.Problem`.
  `item_errors` moved to `ConflictError` and holds `bookshelf.ItemError` values.
- `correct_book()` takes keyword arguments (`reason`, `description`, `authors`, `discovery` and `metadata`)
  in place of a `models.BookCorrection`, and returns a `BookCorrection`.
  Pass `metadata={}` to clear the metadata.
