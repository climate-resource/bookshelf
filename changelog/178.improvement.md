Recorded the pyarrow writer version in the bundle manifest header, under a new optional `writer` block,
and bumped the manifest schema to `1.1`.
Parquet output is not stable across pyarrow versions,
so this makes a change in the recorded content hashes explain itself.
Also corrected the bundle format specification and the `BundleUsedRef` docstring,
which both claimed that a recorded `used` reference is never resolved again.
A recorded `tracking_id` is rewritten at replay to the id the server returned,
and a `logical_key` is resolved by the server at registration time.
