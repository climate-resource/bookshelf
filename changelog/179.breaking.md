Replaces the flat recipe with `volume:`, `defaults:`, `build:` and `books:` sections,
and made `bookshelf record --version` required.

- A recipe declares the volume once, the defaults once, the build once, and each book explicitly.
- Unknown keys are rejected at every level, rather than silently ignored.
- `collection`, `authors` and `notebook` moved under `volume:` and `build:`.
  The flat form no longer loads, and a recipe using it is rejected with a message naming the new shape.
- `books:` is a list, one entry per book, each stating its own `version:`.
  The section reads in the same words as the platform, where a volume holds books.
  Two books claiming one version are rejected.
- `defaults:` holds what every book starts from, and a book overrides any of it field by field.
  It carries `discovery:`, `visibility:` and `resources:`.
- `discovery:` moves from `volume:` to `defaults:`.
  Every field of it is a fact about a book that the recipe merely supplies a starting value for.
  A `discovery:` under `volume:` is rejected with a message naming where it moved.
- A resource default supplies the fields that do not move between books, `type` most of all,
  so a book states only its `uri:` and `sha256:`.
  A default is a template, so a book that never names the resource does not get it.
  A book stating its own `path:` or `uri:` replaces the default's location rather than joining it.
- `visibility:` may now be defaulted, because an embargo usually covers a whole feedstock.
  Where neither the defaults nor the book state it the book is `hidden`.
  A `visibility:` under `build:` is rejected with a message naming where it moved.
- Every book states its own `license`, and there is no default for it.
  A `license` under `volume:` is rejected with a message saying to move it onto each book.
- `topics:` is gone. It never named a curated set, and nothing distinguished one from a keyword.
  Use `keywords:`.
- The inputs a book is built from are declared under `resources:`,
  and each states a `type` from the same set the platform registers a resource under.
  An unknown type is rejected when the recipe loads, naming the ones that are allowed.
- `--version` selects the book to record, and it is the only place a version is stated.
  A build file calls `bookshelf.setup()` without a version, and `-p` is unchanged.
- `ResolvedVersion` is now `ResolvedBook`, and `VersionSpec` is now `BookSpec`.
