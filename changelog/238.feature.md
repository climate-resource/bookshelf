Added `Bookshelf.ensure_authenticated()` and its async twin,
which confirm the API accepts the client's credential.
A missing or spent stored login now starts a browser login from a local terminal,
or a device code login from a notebook, an SSH session or a terminal with no browser.
CI client credentials and `BOOKSHELF_TOKEN` are verified but never replaced.
Without a person to log in, it raises the new `AuthenticationRequiredError`.
Drafting a book now runs the same check first, unless the client was created with `auth=None`.
