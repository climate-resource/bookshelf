Publishes the bundle format as a specification at `docs/explanation/bundle-format.md`.

A bundle can be produced, reviewed and validated with no server involved, so the format is useful to a
project that keeps its own scientific outputs on disk and wants to record what produced them.
The document describes the bytes on disk rather than the Python interface, so an implementation in
another language can be written from it.
It covers the directory layout, the manifest schema field by field, the `managed` and `pointer`
discriminator, lineage, determinism, versioning, the validation rules, and what a bundle deliberately
does not carry.
