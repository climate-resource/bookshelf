Added `Bookshelf.ensure_authenticated()` and its async twin,
which confirm the API accepts the client's credential.
A missing or spent stored login now started a browser login from a terminal,
or a device code login from a notebook or a terminal with no browser.
CI client credentials and `BOOKSHELF_TOKEN` were verified but never replaced.
Without a person to log in, it raised the new `AuthenticationRequiredError`.
Drafting a book now ran the same check first, unless the client was created with `auth=None`.
