Hardened `bookshelf record` and `bookshelf validate` against the cases the b20 stress test found.

- `record --force` now compares its target with the feedstock by file identity,
  so a differently cased path on macOS can no longer replace the feedstock.
- `record --force` now replaces only a directory holding a parseable bundle manifest and nothing else,
  and it refuses a symlinked `--bundle`.
- A `-p` parameter bound by a chained assignment such as `M = K = 2` is now refused before the build runs.
- A duplicate resource name in a build is now reported without a traceback.
- `validate` no longer hangs on a FIFO in place of a resource file.
- `validate` now refuses a managed resource without `size`, a book without `processing`,
  and a manifest key the schema does not define, such as a misspelt `visiblity`.
