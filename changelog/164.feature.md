Publishes the bundle format as a specification at `docs/explanation/bundle-format.md`.

A bundle can be produced, reviewed and validated with no server involved,
so the format is useful to a project that keeps its own scientific outputs on disk
and wants to record what produced them.
The document describes the bytes on disk rather than the Python interface,
so an implementation in another language can be written from it.
It covers:

- the directory layout, and how a byte file name is derived
- the manifest schema, field by field, with required and optional marked
- the `managed` and `pointer` discriminator, and why it is explicit
- lineage, and the optional activity envelope
- determinism, versioning, and the validation rules
- what a bundle deliberately does not carry, the edition most of all
